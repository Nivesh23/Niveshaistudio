One quick step to enable the animation

Chrome blocks local file access for security. To load the cinematic scroll animation, run a local server from your Downloads folder:

cd C:\Users\NIVIP\Downloads python -m http.server 8080

Then open in your browser:

http://localhost:8080/Nivesh%20Ai%20solutions/luxury-studio.html

The rest of the site (all sections below) works perfectly right now — only the scroll animation needs the server.
